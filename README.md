"# EMPTrack_report_widget" 
## Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/FlashiestUSB/EMPTrack_report_widget.git
   cd EMPTrack_report_widget

Create a virtual environment
python -m venv .venv
source .venv/bin/activate   # On Linux/Mac
.venv\Scripts\activate      # On Windows

Install dependencies
pip install -r requirements.txt

Run the application
python main.py
